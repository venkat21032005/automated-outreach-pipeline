# Sample Outreach Outputs - Verification Packages

This folder contains verified sample output data payloads generated by the outreach pipeline. To comply with professional standards and protect active developer API keys, these samples are generated from the pipeline's E2E validation simulation runs.

---

## Output Labels

- **`sample_summary.json`** ──> **`SIMULATION OUTPUT`**
  *Contains metadata, timestamps, and pipeline transition counts.*
  *Link: [sample_summary.json](sample_summary.json)*

- **`sample_leads.json`** ──> **`SIMULATION OUTPUT`**
  *Contains deduplicated decision-maker records with resolved work emails and titles.*
  *Link: [sample_leads.json](sample_leads.json)*

- **`sample_sent.json`** ──> **`SIMULATION OUTPUT`**
  *Contains transaction logs of successfully dispatched outreach emails returned by Brevo.*
  *Link: [sample_sent.json](sample_sent.json)*

- **`sample_errors.json`** ──> **`SIMULATION OUTPUT`**
  *Contains structured records of any partial API failures captured during the run.*
  *Link: [sample_errors.json](sample_errors.json)*
